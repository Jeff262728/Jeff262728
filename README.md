#

<p align="center">Estudante de Engenharia de Software na Faculdade de Anhanguera Unopar de Mogi Guaçu, com foco em desenvolvimento de software, arquitetura de sistemas e criação de soluções escaláveis.

Atualmente atuo com C#  no desenvolvimento de aplicações e APIs performáticas, enquanto aprofundo meus conhecimentos em Java, expandindo minha base em programação orientada a objetos, boas práticas e padrões de projeto.

Como desenvolvedor, estou em constante evolução técnica, buscando desafios que me permitam aplicar conceitos de engenharia de software na prática. Tenho forte interesse tanto em desenvolvimento de jogos quanto em aplicações web fullstack, unindo lógica, performance e experiência do usuário.

Sou movido por aprendizado contínuo, resolução de problemas e construção de soluções inovadoras que gerem impacto real. Busco oportunidades onde eu possa contribuir com tecnologia, criatividade e visão de produto.
